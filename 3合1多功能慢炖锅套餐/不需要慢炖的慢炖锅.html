1

用户层面：你以为用户在买慢炖，其实他们在买"那个味道"

用户在购买慢炖锅的时候，脑子里想的从来不是"把锅设好然后等几个小时"——他们想的是烹饪的终点，是端上桌的那一刻。

🧡

他们真正想要的

  • 软烂入味的炖菜口感
  • 肉酥而不柴的质地
  • 调味料充分渗透进食材
  • 端上桌有食欲的卖相
😅

他们实际上在忍耐的

  • 等上几个小时才能吃
  • 出门前必须提前设好
  • 中途想改菜根本没机会
  • 下班到家才有得吃
结论：慢炖对用户而言是手段，不是目的。目的永远是风味，等待是不得不承受的代价。
2

需求层面：风味是三层递进的心理需求

从用户需求往下深挖，会发现风味是一个三层递进的结构——传统慢炖锅只能满足其中一到两层。

层次 需求本质 用户心理 传统慢炖锅
表层 软烂口感 食物好不好吃，入口即化是基本期待 ✅ 满足
里层 风味渗透 调味料、肉汁、香气能不能真正进到食材纤维里 ✅ 满足
深层 烹饪体验 随时打开就用，灵活掌控，不用等几个小时 ❌ 牺牲

💡 真正的机会点

用技术手段同时满足里层和深层需求——这才是差异化竞争的真空地带。

3

技术与产品层：两套核心武器，对应两个关键条件

慢炖风味的本质，是"足够的热渗透深度 + 适当的焖煮时间 + 能锁住风味不流失的容器"。我们有两套技术各自对应其中一个条件。

🔗 核心原理链路：tr1 如何做到"不需要慢炖"

  1. 电陶炉【高热红外】 加热上面的塔吉锅
  2. 激发塔吉锅【紫砂】材质辐射【远红外】
  3. 被烹煮食物中水/脂肪/蛋白等有机分子，在 4-14 μm 自运动最活跃波段，吸收同波长远红外后形成增幅共振
  4. 分子动能→势能热 + 分子间摩擦热 + 分子键断裂瞬时高温 = 食物【自加热】
📐 物理基础：维恩位移定律 λmax = 2898/T (μm·K) — 烹饪温度 100-250°C 对应辐射峰值 5.54-7.77 μm，正好落在 3-15 μm 远红外黄金波段内。

📊 三种天然材质远红外发射率对比

红外发射率 ε（Emissivity）：越接近 1，辐射效率越高。紫砂、陶瓷、铸铁在烹饪温度下都辐射远红外，但紫砂效率最高。

材质 ε 发射率 关键差异
天然紫砂（无釉） 0.92-0.94+ Fe₂O₃ 8-12% + 双重气孔"微体腔辐射"
普通陶瓷（带釉） 0.90-0.92 玻璃釉层阻挡、折射电磁波
珐琅铸铁 ~0.90 表面釉层

💡 结论：在纯天然、无涂层的烹饪材质中，紫砂远红外辐射效率最高 — 天然富含 Fe₂O₃（8-12%）、Ti、Mn 等过渡金属氧化物（工业上制作高性能远红外陶瓷的核心添加剂），加上双重气孔结构形成的"微体腔辐射"效应（每个微孔 = 微型黑体腔，对红外线多次反射折射）。

富硒紫砂·全陶瓷塔吉锅

风味渗透的介质

为什么能锁住风味？

  • 紫砂高气孔率带来"呼吸感"——允许少量蒸汽循环但不过度流失
  • 调味料和肉汁慢慢渗透进食材纤维，同时锁住本味
  • 相比金属/不粘锅，热传导快但冷却也快，食材表层迅速收紧——风味反而进不去

紫砂 vs 普通锅

金属/不粘锅热快凉快，表层封闭
→

① 紫砂"双重气孔"微观结构（Dual-Pore Structure）

紫砂矿土在 1100-1250℃ 烧结时，不会完全玻化（不像普通瓷器密实），会形成两种气孔的共生结构：

  • • 闭口气孔（团聚体内部）：孔径 ~1.3μm → 充当热的不良导体，起锁温保温作用
  • • 开口气孔（团聚体之间）：孔径数微米 → 允许气态水蒸气缓慢进出，但液态水因表面张力无法穿过

② 塔吉锅微冷凝循环（Micro-circulation）

塔吉锅特有的高帽锥形盖在烹饪中起"无水冷凝器"作用：

  • 1. 锥盖上部远离热源，温度显著低于锅底
  • 2. 食材水分受热蒸发 → 升腾到锥盖顶部 → 迅速冷凝
  • 3. 水滴沿陡峭锥壁滑落 → 重新回到锅底
  • 4. 气-液自循环，无需额外加水，保留挥发性风味物质

③ 陶瓷低导热系数（Low Thermal Conductivity）

陶瓷/紫砂的导热系数 0.8-1.2 W/(m·K)，远低于金属（铁 ~80，不锈钢 ~16）。这意味着：

  • • 加热速度温和 → 食材表层肌肉蛋白缓慢变性（不剧烈收缩）
  • • "风味通道"保持舒张 → 调味料/肉汁能持续渗透进深层纤维
  • • 陶瓷是热的不良导体 → 离火后余温持续加热（节能 + 焖煮效果）
⟶ 紫砂 0.8-1.2 W/(m·K) ≪ 铁 80 W/(m·K) ≈ 100× 导热差

远红外电陶炉

快速穿透的热源

为什么能快速热透？

  • 远红外波长对应水分子共振频率，热量从内到外加热食材（非传统热传导从外往里烤）
  • 同样时间内，深层风味物质更容易释放到汤汁里
  • 表层不会因高温快速焦化封闭，风味通路保持畅通

远红外 vs 普通加热

普通热传导外焦里生，热不均匀
→
远红外从内到外，渗透均匀

① 分子转动-振动能级与共振吸收（Resonance Absorption）

根据红外光谱学原理，极性分子（水、蛋白质、有机物）的振动/转动能级对应 2-25μm 红外波段。水分子 O-H 键的强吸收带：

  • • 3μm 附近：O-H 拉伸振动强吸收
  • • 5-15μm 远红外波段：O-H 弯曲振动，与本产品辐射波段重叠
λ = 6-14μm (远红外)

② 体积加热（Volumetric Heating）vs 传统表面传导

远红外电磁波具有一定的穿透深度（含水食材中通常为亚毫米级），意味着热量在一定深度内内外同时激发，而不是从表面"排队往里钻"。

③ 避免表面硬化（Prevention of Case Hardening）

传统高温热风/传导加热 → 食材表面水分瞬间蒸发 → 形成致密碳化壳（Case Hardening） → 关闭物理毛细孔 → 阻止内部水分蒸发 + 阻碍深层风味物质溶出。

远红外加热内外温差小 → 表面不焦化闭合 → 风味通道保持舒张 → 氨基酸/核苷酸等鲜味物质持续溶出。
